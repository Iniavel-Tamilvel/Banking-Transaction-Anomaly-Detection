# Banking Transaction Anomaly Detection

An unsupervised-learning project for prioritising unusual banking transactions for human review.

**Workflow:** data quality → EDA → feature scaling → Isolation Forest → anomaly ranking → operational interpretation.

**Important:** this uses synthetic demonstration data. An anomaly is not evidence of fraud or financial crime.

## Run
```bash
pip install -r requirements.txt
python notebooks/banking_anomaly_analysis.py
```
