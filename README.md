# 🏦 Banking Transaction Anomaly Detection

## Unsupervised Machine Learning for Transaction Monitoring

An end-to-end **Data Science and Machine Learning project** that identifies statistically unusual banking transactions using **Isolation Forest** and prioritises them for potential human review.

The project demonstrates a complete analytical workflow covering:

- Synthetic transaction-data generation
- Data-quality validation
- Exploratory Data Analysis (EDA)
- Behavioural feature engineering
- Unsupervised anomaly detection
- Anomaly scoring
- Behavioural risk analysis
- Model validation
- Review-priority classification
- Responsible AI and model-governance considerations

> **Important:** This project uses a synthetic banking dataset. An anomaly represents statistically unusual behaviour identified by the model and does **not** indicate confirmed financial crime.

---

# 📌 Project Overview

Financial institutions process large volumes of transactions and need analytical methods to identify activity that differs substantially from expected behavioural patterns.

This project investigates how an **unsupervised machine-learning approach** can identify unusual transactions without requiring a traditional fraud-labelled training dataset.

The workflow is designed around a **human-review prioritisation approach**, rather than automated financial-crime decisions.
